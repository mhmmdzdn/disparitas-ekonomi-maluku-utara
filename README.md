# Disparitas Ekonomi Maluku Utara

Platform analisis dan visualisasi interaktif mengenai disparitas ekonomi antarwilayah di Provinsi Maluku Utara.

## Fitur Utama
- **Visualisasi Interaktif**: Peta spasial Kabupaten/Kota Maluku Utara dengan metrik PDRB, PDRB per kapita, dan IPM.
- **Analisis Disparitas**: Indeks Williamson, perbandingan kontribusi sektor tambang vs non-tambang.
- **Narrated Slide / Audio Tour**: Presentasi berbasis slide dengan audio penjelasan dan navigasi keyboard/touch.
- **Data Historis**: Kompilasi data BPS Maluku Utara 2015–2026.

## Menjalankan Secara Lokal
Buka file `index.html` secara langsung di browser atau gunakan server statis:
```bash
npx serve .
```

## Deployment
Aplikasi statis ini di-deploy secara otomatis menggunakan [Vercel](https://vercel.com).
